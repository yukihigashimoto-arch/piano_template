GitHub Pagesアップロード用（フォルダなし）

このZIPを解凍すると、すべてのファイルが同じ階層にあります。
GitHub > Add file > Upload files > choose your files で、全ファイルを複数選択してアップロードしてください。

必須ファイル:
- index.html
- style.css
- school-config.js
- app.js
- hero.svg
- about.svg
- teacher.svg
- feature-1.svg
- feature-2.svg
- feature-3.svg

教室ごとの変更:
- school-config.js を編集
- note のURLは news.profileUrl / news.feedUrl を変更

NEWS:
- GitHub Actionsは使いません。
- note RSSをRSS→JSON変換サービス経由でブラウザから取得し、最新記事を表示します。
